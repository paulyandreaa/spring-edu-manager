# 🎓 SpringEduManager - Gestión Académica

## 📖 Descripción
Aplicación web educativa desarrollada con el ecosistema Spring para centralizar la gestión académica de un bootcamp de programación. Reemplaza el uso de hojas de cálculo dispersas con una plataforma unificada, segura y escalable que permite administrar estudiantes, cursos, prácticas y evaluaciones.

## 🛠️ Tecnologías Utilizadas
- **Backend:** Java, Spring Boot, Spring MVC
- **Seguridad:** Spring Security (RBAC - Control de Acceso Basado en Roles)
- **Persistencia:** Spring Data JPA, MySQL
- **API:** REST API
- **Herramientas:** Eclipse Enterprise Edition, Maven

## ✨ Características Principales
- **Control de Acceso Basado en Roles (RBAC):** 
  -  **Administradores:** Pueden registrar alumnos, asignarlos a carreras, gestionar matrículas y administrar todos los datos del sistema.
  - 👨‍🎓 **Estudiantes:** Acceso de solo lectura para consultar sus cursos, prácticas y evaluaciones.
- **Gestión Integral:** CRUD completo de estudiantes.
- **Arquitectura Moderna:** Implementación de patrón MVC con separación clara de responsabilidades.
- **API REST:** Endpoints bien definidos para integración con futuros módulos del campus.
- **Seguridad:** Autenticación y autorización robusta con Spring Security.

## 🚀 Funcionalidades
- Registro y gestión de estudiantes
- Asignación de alumnos a carreras
- Control de estado de matrícula
- Panel administrativo completo
